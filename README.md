# sc-miRNA-COVID
Codes for analysing and predicting miRNA expression at single cell resolution from paired bulk miRNA and mRNA expression data combined with scRNA-seq data

## miRNA_deconv_pipeline.R
The main pipeline for miRNA prediction.
## decontX.R
Ambient RNA detection
## correlation.R
Spearman correlation between nominally significant DEGs and inferred miRNAs
## external_validation.R
Independent validation of the genes using GSE
